## Как эту дичь запустить

### 1. склонировать эту дичь себе

```bash
git clone названиеРепозитория
cd названиеПапки
```

### 2. все зависимости подключить

```bash
npm install
```

потом у вас должно все установиться: express и pg

### 3. создайте файлик для настройки к бд у себя локально

cоздайте файл `.env` (прям так и назовите) в самом корне проекта

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=pet_hotel
DB_USER=username
DB_PASSWORD=password
```

**н!!но!!** замените значения на свои реальные данные подключения к Postgre

### 4. Дальше

У вас скорее всего ниче не покажется потому что бд то пустая)

### 5. запуск сервера
чтоб запустить сервер в терминале пропишите

```bash
node server.js
```

после запуска сервер будет на : `http://localhost:3000`


При успешном подключении к БД вы должны получить данные из таблицы `users` в формате JSON.

## структура проекта

```
pet_hotel/
├── server.js          # Основной файл сервера
├── public             # Основная страница
├── .env               # Переменные окружения (создать самостоятельно)
├── package.json       # Зависимости проекта
└── README.md          # Этот файл
```
